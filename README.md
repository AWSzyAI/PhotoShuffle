# 照片随放 · PhotoShuffle

![玫瑰图标](assets/icon.png)

让系统照片图库在空闲时随机播放的 macOS 菜单栏小工具。支持多显示器分别随机播放，可为每块屏幕独立开启或关闭照片展示。支持 macOS 13 或更新版本，以及 Apple Silicon / Intel Mac。

## 安装与首次使用

下载 Release 中的 Universal DMG，打开后把“照片随放.app”拖到 Applications，再启动。

应用采用 **ad-hoc 本地签名，未经 Apple 公证**。Gatekeeper 可能拦截首次运行；请确认下载来源，再在“系统设置 → 隐私与安全性”中针对这一应用选择允许打开。无需也不建议关闭系统保护。

首次启动仅显示设置，自动播放和登录时启动默认关闭，不主动申请图库权限。

1. 点击“授权并读取图库”。macOS 实际授予**读写图库权限**，但本工具代码只查询和显示，没有修改、删除或导入照片的调用。
2. 点击“立即播放”体验。默认每 10 秒切换，可选 5 / 10 / 20 / 30 秒。
3. 按需开启“空闲自动播放”，空闲可选 30 秒 / 1 / 3 / 5 / 10 分钟；需要时开启“登录时启动”。

默认在 Dock 中显示玫瑰图标；可在设置或菜单中关闭，关闭后仍保留菜单栏入口。点击 Dock 图标可重新打开设置。

应用在菜单栏中提供设置和退出入口；设置窗口也有退出按钮。应用活动时可按 Command-Q 退出。

## 播放操作

| 操作 | 按键 |
| --- | --- |
| 结束播放 | Esc |
| 暂停 / 继续 | 空格 |
| 上一张 / 下一张 | 左 / 右方向键 |
| 在系统“照片”中打开当前图片 | O / Return |

移动鼠标显示控制条。静态交叉渐变不缩放或平移，默认 1 秒，可选关闭 / 0.5 / 1 / 1.5 / 2 秒。时长和缓动曲线是本工具的设计选择，不声称精确复刻系统“照片”。加载下一张时保留当前图片；过渡期间暂时禁用打开，结束后定位新图。提前准备接下来 3 张实际图片（不只是缓存提示），按屏幕尺寸加载并限制最长边 2560 像素。首张未准备好时不显示黑色播放器；后续图片尚未就绪时继续展示旧图。取消预取或结束播放会归还未展示索引、释放图片缓存；同一次应用运行内按屏幕保留洗牌进度，重新读取图库时重置。切换计时从图片完成加载后开始；单张加载超时会跳过，连续失败有上限，可手动继续或结束。

## 多显示器

在设置的屏幕列表中分别勾选需要展示的显示器，默认全部开启。关闭的屏幕保留桌面；全部关闭时不会开始播放。每块屏幕独立切换、暂停、前后浏览，并提前准备 3 张图片。屏幕间协调选图，在图库足够时避免同时显示同一张；上一张操作也遵守该限制。若所需图片正在另一屏展示，会保留旧图等待，图库少于启用屏幕数时允许重复。每屏独立洗牌；多屏互斥可能使本轮图片延后展示、轮次重叠，因此不承诺多屏模式严格轮内不重复。

将鼠标移到需要操作的屏幕，或点击该屏幕控制条，即可操作对应照片；“在照片中打开”定位该屏幕当前图片，并退出整组播放，Esc 或结束按钮同样结束全部屏幕。显示器接入、断开或布局变化会结束本轮展示并刷新列表，下次使用新的屏幕配置。

## 图库与隐私

- 使用 PhotoKit 的系统主图库来源，包含归属于主图库的 iCloud 共享图库；隐藏和最近删除项目不纳入。独立共享相簿、iTunes 同步来源不在当前支持范围内。
- 保留完整图库索引并只洗牌索引，每块启用屏幕仅保留当前图片与最多 3 张预备图片，不复制图库、不批量下载、不持久保存图片。iCloud 照片由 PhotoKit 按当前屏幕尺寸按需读取。
- 授权后观察图库变化，不打断当前展示；结束或下一次播放前刷新索引。也可手动重新读取图库。
- App Sandbox 开启，仅声明照片图库 entitlement，没有网络客户端 entitlement。代码不使用 AppleScript，也不要求 Automation 权限。
- “在照片中打开”使用系统 `photos:` URL。该未公开行为可能随 macOS 版本改变，不能保证所有系统版本或特殊图库项目都能准确定位。[实现参考](https://damian.fyi/swift/2024/01/01/opening-a-photo-in-apple-photos-from-swift-on-macos.html)。

## 屏保、锁屏与睡眠

本工具使用普通窗口，不替代安全锁屏，不修改或阻止系统屏保、锁屏、睡眠与唤醒。系统屏保、锁屏或屏幕睡眠时停止展示；照片 App 处于前台时不自动播放。

请自行选择空闲播放间隔与系统屏保间隔：如果系统屏保先启动或随后接管，照片展示会中止。应用不会为延长展示而弱化系统安全设置。

## 更新后的照片授权

目前发布包使用本地签名。更换版本或重新编译后，macOS 可能不再接受旧版的照片授权，即使系统设置仍显示“完全访问”。请先退出应用，在“系统设置 → 隐私与安全性 → 照片”中为“照片随放”重新确认访问，再启动应用并点击“授权并读取图库”。如果系统弹出新的授权提示，请根据自己的选择确认；无需开放完全磁盘访问或关闭系统安全保护。

## 从源码构建

需要 Xcode Command Line Tools（Swift、系统 macOS SDK、Python 3），不需要第三方依赖。

```sh
zsh build.sh                 # 当前架构
zsh build.sh --universal     # arm64 + x86_64，macOS 13+
zsh package-dmg.sh          # dist/ 中生成 DMG 和 SHA-256
```

图标由随仓库的裁剪 PNG 生成标准尺寸 iconset 和 ICNS；原照片与原始 EXIF/GPS 元数据不进入仓库。编译、签名及磁盘镜像 staging 在系统临时目录完成，避免云盘扩展属性污染签名。

构建先对当前机器架构运行 `--self-test`，覆盖洗牌、URL 编码和自动触发纯逻辑；自检不申请照片权限、不读取图库。Universal 版本包含两种架构，但交叉编译不能替代 Intel 实机运行验证。

构建结果为 `build/照片随放.app`。最终沙盒二进制不适合直接从终端运行；通过 Finder 或 Launch Services 启动应用。

目前未指定开源许可证；公开源码不代表已授予额外使用、修改或再分发许可。
